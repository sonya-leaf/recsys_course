1. Создание фреймворка для сопоставления рекомендаций от разных моделей 
2. Имплементация алгоритма h-indexer из статьи Retrieval with Learned Similarities на датасете Yambda-5B и его сравнение с альтернативными подходами  
3. Разработка домашнего задания на тему “Кросс-доменные рекомендации” для курса по рекомендательным системам 
4. Полевое социологическое исследование на тему “как рекомендации влияют на нашу продуктовую корзину” 

Семинарские часы курса будут использованы для консультаций. На каждом занятии студентам необходимо обозначить свой текущий прогресс.

На последнем семинаре / консультации перед экзаменом нужно презентовать результаты работы. Формат сдачи — презентация (каждый участник команды должен говорить) и сопутствующие артефакты (код/статья/эссе/etc)
