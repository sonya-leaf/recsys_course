# Домашнее задание 2 — Candidate Retrieval

Цель — построить и сравнить методы отбора кандидатов на датасете Amazon Reviews 2014.
Используется категория **Beauty, 5-core**. Для базовых моделей GPU
не нужен; Transformer можно обучать с небольшими параметрами на CPU. Источник данных:
McAuley Lab, UCSD.

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python ../download_data.py
jupyter lab homework.ipynb
```

Общий скрипт создаёт `../data/interactions.parquet`, `../data/items.parquet` и
`../data/users.parquet`. Повторный запуск безопасен; `--force` скачивает данные заново.
Для быстрой отладки можно передать `--max-reviews 10000`.

## Как устроена работа

Каждый программный шаг задаёт точную сигнатуру, схему результата, формулу и правила
для граничных случаев. Сразу после него находится вызов `tests.check_*`. Переходите
дальше только после сообщения `All good! :)`. 

Тесты запускаются непосредственно из ноутбука (`import tests`); их аргументом является
реализованная функция или класс. Не изменяйте `tests.py`. Фиксируйте seed. Не
используйте test split данных при подборе параметров.

Сдача: ветка `hw2` приватного репозитория, заполненный `homework.ipynb`.
