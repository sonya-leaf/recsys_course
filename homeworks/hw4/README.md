**Цель работы:** разработать полноценный сервис рекомендаций, состоящий из трёх компонентов: бэкенд-симулятор пользователей, API для генерации взаимодействий и оркестратор (Airflow) для обучения и инференса моделей в пакетном режиме.

**Задачи:**

- Реализовать бэкенд-сервис на FastAPI с PostgreSQL:
  - Таблицы: 
    - users,
    - items,
    - interactions,
    - recommendations.


  - Инициализация базы из данных Amazon 2014.
  - CRUD-операции для всех таблиц.
  - Резервирование строки row_id = 0 в таблице рекомендаций для дефолтных рекомендаций.
- Реализовать симулятор поведения пользователей — отдельный FastAPI-процесс, который генерирует и добавляет новые взаимодействия в PostgreSQL.
- Реализовать три DAG-а в Apache Airflow:
  - train_retrieval — обучение retrieval-моделей на данных из PostgreSQL, сохранение артефактов.
  - train_ranking — обучение ranking-модели на основе retrieval-кандидатов.
  - inference — инференс пайплайна (retrieval + ranking) для всех активных пользователей, запись топ-N рекомендаций в таблицу.
  - recommendations (с обновлением строки row_id = 0 для дефолтных рекомендаций).


- Настроить Docker-compose для оркестрации трёх сервисов (два FastAPI + Airflow с PostgreSQL) с общей базой данных.
- Оформить README с инструкцией по сборке и запуску проекта.
